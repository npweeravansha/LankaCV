PDF එකක් විදිහට CV එක Save කරන්නේ කොහොමද?

CV එක හදාගෙන ඉවර වුණාම පහත steps ටික follow කරන්න.

1

CV එක සම්පූර්ණ කරන්න

Personal Details, Education, Experience, Skills වගේ අවශ්‍ය තොරතුරු සියල්ල ඇතුළත් කරන්න.

2

CV Preview එක බලන්න

දකුණු පැත්තේ Preview එක බලලා සියලුම details හරියට පේනවාද කියලා check කරන්න.

3

Download / Save as PDF ඔබන්න

Builder එකේ පහළ තියෙන Download / Save as PDF button එක ඔබන්න.

4

Print window එක එනකම් ඉන්න

Chrome / Edge වගේ browser එකේ Print window එක open වෙයි.

5

Save as PDF තෝරන්න

Destination හෝ Printer කියන තැනින් Save as PDF තෝරන්න.

6

Save කරන්න

File name එක දාලා Save කරන්න. දැන් ඔයාගේ CV එක PDF file එකක්.

💡 Tip: Print window එකේ Background graphics option එක තිබුණොත් ON කරන්න. එතකොට CV එකේ colors සහ sidebar design එක හොඳට PDF එකට එනවා.
