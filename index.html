PDF එකක් විදිහට CV එක Download කරන්නේ කොහොමද?

CV එක හදාගෙන ඉවර වුණාම පහත steps ටික follow කරන්න.

1

CV එක සම්පූර්ණ කරන්න

Personal Details, Education, Experience, Skills වගේ අවශ්‍ය තොරතුරු සියල්ල ඇතුළත් කරන්න.

2

Download / Save as PDF ඔබන්න

CV Builder එකේ පහළ තියෙන “Download / Save as PDF” button එක ඔබන්න.

3

Print window එක එනකම් ඉන්න

Browser එකේ Print window එක open වෙයි.

4

Destination / Printer එක තෝරන්න

Computer එකේ නම් Save as PDF තෝරන්න. Phone එකක නම් Print options වල PDF / Save as PDF option එක බලන්න.

5

Save කරන්න

File name එකක් දාලා Save කරන්න. දැන් ඔයාගේ CV එක PDF file එකක්.

💡 Tip: PDF එක save කරන්න කලින් Preview එකේ CV එකේ සියලුම details හරියට තියෙනවද කියලා බලන්න.
